id: fm-02
title: Data changes while it is being copied
keywords: data copy, replication, writes, lost writes, cutover, consistency, snapshot, stale data, sync

A copy of a data store is only a snapshot of one moment. Writes that arrive after the copy starts can be missing from the new copy unless they are stopped or replicated until the cutover. Without a plan for those writes, the new environment can start with data that is already out of date.
