title: Messages in flight during a message bus move
keywords: message bus, queue, broker, messages, in flight, duplicate, lost messages, producer, consumer, topic, kafka, events

Messages already sent to the old message bus can be left unread if the consumers move to the new one first. If producers and consumers disagree about which bus is current, messages can be lost or processed twice. Producers and consumers need a clear rule for which bus each side uses at each step, and a way to drain what is already queued.
