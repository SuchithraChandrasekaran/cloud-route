id: fm-08
title: A component receives requests before it is ready
keywords: readiness, health check, startup, ready, warm up, probe, traffic, routing, not ready, errors on start

A component that has started is not always ready to serve. If requests are routed to it before it has loaded its data or reached its own dependencies, callers get errors. A readiness check that confirms the component can serve a real request, and routing only after it passes, avoids sending requests to it too early.
