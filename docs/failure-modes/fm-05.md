title: Secrets and credentials missing in the new environment
keywords: secrets, credentials, password, api key, token, certificate, tls, access, permissions, identity, iam, vault

A component that works in the old environment can fail on its first start in the new one because a secret, a credential or a permission was not copied. The failure often shows up as an authentication error, not a missing file. Listing every secret and permission a component uses before it moves makes these gaps visible early.
