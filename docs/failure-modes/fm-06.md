title: Dependencies that are not declared
keywords: undeclared dependency, hidden dependency, environment variable, hard-coded address, configuration, service discovery, missing edge, dependency map, incomplete

A component can call another through an address held in an environment variable or in code. Tools that build a dependency map from declared relations cannot see such a call. An order computed from an incomplete map can move a component before something it needs. Declaring those calls explicitly, where the tool supports it, closes the gap.
