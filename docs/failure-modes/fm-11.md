title: Calls that cross between old and new environments
keywords: cross environment, hybrid, split, partial migration, firewall, egress, latency, network path, security group, traffic between environments

During a migration, some components run in the old environment and some in the new, so calls between them cross the boundary. Firewall rules, security groups and routing must allow those calls. They are also slower than calls inside one environment and may carry transfer charges. The longer a plan keeps a component away from the components it calls, the longer this applies.
