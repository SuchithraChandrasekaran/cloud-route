title: Version mismatch between a caller and the service it calls
keywords: version, api, schema, compatibility, contract, upgrade, request format, breaking change, mismatch

When one side of a call moves and is upgraded while the other stays, the request format or the data schema may no longer match. The failure appears at the first call between the two versions. Keeping the interface unchanged during the move, or confirming both versions accept each other's requests, avoids this
