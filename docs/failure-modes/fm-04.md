title: DNS changes are not instant
keywords: dns, ttl, cache, cached, resolver, hostname, cutover, address, propagation, clients still using old address

A DNS record can stay cached by clients and resolvers until its time to live expires. After a cutover, some clients keep sending requests to the old address for that long. If the old environment has already been shut down, those requests fail. Checking the record's time to live before the cutover shows how long the old address can still receive requests.
