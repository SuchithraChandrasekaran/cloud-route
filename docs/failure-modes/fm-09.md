title: Rolling back a component that holds data
keywords: rollback, roll back, revert, undo, database, stateful, data written after cutover, restore, state, persistent

Routing requests back to the old environment does not undo what the new environment wrote. Data created after the cutover stays in the new environment and is not in the old one. Before a component that holds data moves, decide how writes made after the cutover will be copied back, or accept that they would be lost.
