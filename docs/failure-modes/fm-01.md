title: A service and the database it uses are in different environments
keywords: database, db, data store, connection string, endpoint, service moved first, database moved first, dependency order, calls between environments

If a service moves before the database it uses, the service runs in the new environment while its data is still in the old one. If the database moves first, any service still in the old environment must reach it across environments. In both cases requests cross between the two environments, which adds latency and needs a network path between them. If that path is closed, or the connection settings are not updated, the service fails.
