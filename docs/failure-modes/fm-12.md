title: Monitoring and alerts still watch the old environment
keywords: monitoring, alerts, alerting, dashboards, logs, observability, metrics, on-call, visibility, detect failure

If dashboards, alerts and log collection still point at the old environment, a failure in the new one can go unnoticed. The old environment can also look healthy because it no longer receives requests. Pointing monitoring at the new environment before a component moves lets its first requests be watched.
